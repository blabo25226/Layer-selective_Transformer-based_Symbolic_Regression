# 最重要
| 文献                                  | 主に支える目的 | 判定理由                                                                                                                                           |
| ----------------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **NSRS／NeSymReS / Neural Symbolic Regression that Scales**                   | メイン・サブ1 | 解析対象そのもの。アーキテクチャ、事前学習データ、式生成、BFGS、評価法を理解する基礎。大量の合成式でTransformerを事前学習し、点集合から式を生成するモデルである。([arXiv][1])                                           |
| **TSRM / Explaining the Explainer: Understanding the Inner Workings of Transformer-based Symbolic Regression Models** | メイン     | **現時点で最も直接的な先行研究**。NeSymReSを対象に、attention head・MLP・層から演算子生成回路を発見し、probingと因果的patchingを比較している。([arXiv][2])                                      |
| **IOLE / Is One Layer Enough? Training A Single Transformer Layer Can Match Full-Parameter RL Training**     | メイン・サブ1 | 単一層のみを学習し、全層学習の改善をどれだけ回収できるかをlayer contributionで測るという、LTSRの直接的な方法論的根拠。ただしLLMのRL学習であり、NeSymReSやencoder–decoder SRへそのまま一般化できるとは限らない。([arXiv][3]) |
| **ScaleSR / Scalable Neural Symbolic Regression using Control Variables**                         | サブ1・サブ2 | NeSymReSを引用する後続研究であり、遺伝子トグルスイッチとrepressilatorの動的方程式をSRで回復している。GRN×NSRという点で非常に近い。                                                               |
| **BSR／Boolformer / Boolformer: Symbolic Regression of Logic Functions with Transformers**                      | メイン・サブ2 | Transformer型SRを実際にGRNダイナミクスへ適用した重要例。Boolean GRNなので連続値Hill型ODEとは異なるが、「ニューラルSR内部をGRNタスクで解析する」という研究位置を示せる。([arXiv][4])                            |
| **LNSR / Learning interpretable network dynamics via universal neural symbolic regression**                            | サブ1・サブ2 | 事前学習型SRとニューラルネットを組み合わせ、物理・生化学・生態・疫学などのネットワークダイナミクスを式として推定している。GRN専用ではないが研究領域が非常に近い。([arXiv][5])                                                |
| **NSRforCND／PI-NDSR / Neural Symbolic Regression of Complex Network Dynamics**             | サブ1・サブ2 | ノイズを含む複数軌道から、ノード自身のダイナミクスとエッジ相互作用を式として回復する。GRNをネットワークダイナミクスとして定式化する際の重要な比較対象。([arXiv][6])                                                      |
| **TPSR / Transformer-based Planning for Symbolic Regression**                            | サブ1     | NeSymReSのデコードをMCTSで改善するため、層選択fine-tuning後の探索改善を評価する直接的な比較対象。ただし層解析そのものではない。                                                                    |
| **SINDy / Discovering governing equations from data by sparse identification of nonlinear dynamical systems**                           | サブ1・サブ2 | 動的方程式発見の標準的基準。ニューラルSRの性能を主張するなら、少なくとも方法論上の比較対象として必要。最新のネットワークSR研究でも主要な基準として引用されている。([Nature][7])                                               |
| **GNW / GeneNetWeaver: in silico benchmark generation and performance profiling of network inference methods**                             | サブ2     | 正解ネットワークと動的モデルを持つ合成GRNを生成できるため、式構造・エッジ・軌道の三段階評価に必要。                                                                                            |
| **DREAM4関連資料**                      | サブ1・サブ2 | ノイズ・時系列・摂動を含むGRN評価に必要。ただし、現在挙げているDREAMのWebページは**データ資源であって主要引用論文ではない**。論文中ではGNW論文やDREAM challengeの正式論文を引用するべき。                                  |
| **ND2 / Discovering network dynamics with neural symbolic regression** | サブ2・メイン | **追加分の中で最優先**。NeSymReSとTPSRを明示的に引用し、事前学習ニューラルSRによって高次元ネットワークの探索を低次元問題へ帰着している。10種類のベンチマークで式構造とパラメータを回復し、実データでは既存の遺伝子制御モデルと微生物群集モデルを修正、遺伝子制御データで予測誤差を59.98%削減したと報告。サブ2の「新たなGRN方程式発見」に最も近く、NeSymReS・TPSRの直接的な引用系列であり、高次元ネットワークをどう式発見へ落とすか、また「新規方程式発見」の主張方法を学べる。ただし層解析はしていないため、**ND2が実現したネットワーク方程式発見をNeSymReSの内部層解析と結び付ける**のが本研究の位置づけになる。([Nature][7]) |
| **ODEFormer / ODEFormer: Symbolic Regression of Dynamical Systems with Transformers**                       | サブ1・サブ2 | **最重要**。単一の観測軌道から多次元ODE系を記号列として推定するTransformerで、ノイズや不規則サンプリングに対する頑健性も評価されている。現行のNSRSパイプラインが $(x(t),\ dx/dt) \to f$ であるのに対し、ODEFormerは $\{t,\ x(t)\} \to f$ を直接行うため、「NeSymReS＋有限差分／NeSymReS＋gradient matching／ODEFormer」という問題設定の違いを説明する必要がある。中間層を同様に解析できれば、静的な点集合から式を推定するNeSymReSと軌道からODEを推定するODEFormerで層表現がどう違うか、という発展研究も可能。 |
| **ST_FAPNN / Set Transformer: A Framework for Attention-based Permutation-Invariant Neural Networks**                 | メイン     | NeSymReSのエンコーダは通常のTransformer encoderではなく、Set TransformerのISABとPMAを利用している（NeSymReS補足資料にも設計が明記）。入力点の順序に依存しない集合表現をattentionで処理するモデル。encoderの「層」はISABなのか、inducing pointsの表現を解析するのか、PMAの出力を解析するのか、decoder層とencoder層を同じように比較してよいのかを決めるには内部構造の理解が必須であり、**層解析においてはAIAYNより重要**。 |
| **DecoderLens / DecoderLens: Layerwise Interpretation of Encoder-Decoder Transformers**                     | メイン     | encoder–decoder Transformerの途中のencoder層を最終層の代わりにdecoderへ接続し、その段階で何が出力可能かを調べる手法。低層・中間層で単純な下位課題が解かれる様子を示している。NeSymReSに応用すれば $h_{enc}^{(l)} \to$ 既存decoder $\to \hat{f}^{(l)}$ として各encoder層からどの程度正しい式を生成できるか測れ、「第1層＝単調性のみ／第2層＝使用変数／第3層＝Hill型と多項式の区別／最終層＝式全体」といった層ごとの処理段階を調べられる。単一層fine-tuningとは異なる**学習なしの層解析**として非常に有力。 |
| **CKA / Similarity of Neural Network Representations Revisited** | メイン・サブ1 | CKAを導入・整理した代表的研究。CKAは、異なる初期値や異なる学習データで訓練されたモデル間でも中間表現の対応を比較しやすい指標である。$CKA(H^l_{base},\ H^l_{GRN})$ を計算することで、GRN fine-tuningで大きく変わる層／一般数式表現を維持する層／Hill式に特化する層／多項式FTとGRN FTで共通して変わる層を比較でき、「学習データによって層の中身が変わるか」という問いに対する中心的な解析手法になる。 |
| **CTC_NSR / Can Test-time Computation Mitigate Reproduction Bias in Neural Symbolic Regression?** | メイン・サブ1 | NeSymReS系のNSRでは、モデルが数値的に式を推論するのではなく訓練データ中の式や近い式を再生成するreproduction biasがあると指摘する研究。トークン単位生成では数値整合性を確認しながら構成的に式を生成しにくいとも論じている。GRN fine-tuning後に特定層がHill式を強く表現していても、Hill関数の数値的性質を学習したのか学習データ中のHill式token列を記憶したのかを区別する必要があり、「同じ式構造・異なる定数／代数的に等価だがtoken列が異なる式／学習時に存在しない式構造／Hill式の次数や変数配置がOOD／未知のGRN motif」という分割の根拠になる。symbolic recovery評価設計の基礎。 |
| **DIP / Designing and Interpreting Probes with Control Tasks** | メイン     | probeは中間表現からHill型・活性化・抑制などを分類するのに使えるが、probe自体が分類問題を学習しているだけという危険がある。ランダムラベルなどのcontrol taskを用い、本当に表現から情報を読み出しているのか、probeが訓練データを記憶しているだけなのかを区別するselectivityの考え方を提案している。TSRMもprobingは相関的な情報を検出しても因果的な回路を同定できないと指摘しており、**probeだけで層の役割を結論づけない**ために必要。 |
| **BPAP / Towards Best Practices of Activation Patching in Language Models** | メイン     | activation patchingの実験設定を体系的に検証した論文。patchingでは、置換する活性化の作り方（mean／resample など）や評価指標の選び方によって、重要だと判断される層や回路が変わり得ることを示し、推奨される指標と手順を整理している。**HUIAPと少なくともどちらか一方は必須**。TSRMも、mean patching・resample patching・機能的指標・logit指標によって結果が異なることを具体的に示している。 |
| **HUIAP / How to use and interpret activation patching** | メイン     | activation patchingの使い方と結果の解釈上の注意点を整理した実践的な解説。patchingの結果が「その活性化で十分（sufficiency）」を意味するのか「必要（necessity）」を意味するのか、どの向きにpatchするかで主張が変わる点など、解釈の落とし穴を明示している。**BPAPと少なくともどちらか一方は必須**。 |

# 重要
| 文献                                         | 残す理由                                                        | 優先度が一段下がる理由                        |
| ------------------------------------------ | ----------------------------------------------------------- | ---------------------------------- |
| **ESRT / End-to-end Symbolic Regression with Transformers** | NeSymReS以外の代表的Transformer SRとして必要                           | 主対象モデルではなく、層解析もしていない               |
| **PySR / Interpretable Machine Learning for Science with PySR and SymbolicRegression.jl**                                   | 非ニューラルSRの強力な比較対象                                            | 研究の理論的中核ではなく、主に実験比較用               |
| **SRBench / Contemporary Symbolic Regression Methods and their Relative Performance**                                | 評価指標・ベンチマーク設計・既存手法比較に必要                                     | GRN・ODE・層解析に特化していない                |
| **SINDy-PI / SINDy-PI: a robust algorithm for parallel implicit sparse identification of nonlinear dynamics**                               | Hill式のような分母を持つ有理式やimplicit dynamicsを扱う比較として有用               | 現在のNeSymReSでHill演算子を直接扱えるなら優先度は下がる |
| **dynGENIE3 / dynGENIE3: dynamical GENIE3 for the inference of gene networks from time series expression data**                              | 時系列GRN推定の代表的比較対象                                            | 主にネットワーク構造・制御辺を推定し、明示的方程式回復が目的ではない |
| **LoRA / LoRA: Low-Rank Adaptation of Large Language Models**                                   | 単一層FT、全層FT、LoRAの比較を行うなら重要                                   | 現時点の主目的が「層解析」であり、LoRAは必須ではない       |
| **WeakIdent / WeakIdent: Weak formulation for Identifying Differential Equations using Narrow-fit and Trimming**                              | 微分推定誤差や観測ノイズへの頑健性を比較できる。弱形式を利用し、ノイズ下で方程式を回復する。([arXiv][1])  | Transformer内部解析とは関係が薄い             |
| **CNSR / Controllable Neural Symbolic Regression**                                   | Hill型、使用演算子、正負部分式などの事前知識を条件として与える発展に使える                     | 現在のメイン研究では、制御可能な生成までは扱わない          |
| **NGDSN／DySymNet / A Neural-Guided Dynamic Symbolic Network for Exploring Mathematical Expressions from Data**                       | ニューラル誘導型SRの別系統として比較できる                                      | Transformer層解析やGRNとの直接的関係が弱い       |
| **ODEG / ODE parameter inference using adaptive gradient matching with Gaussian processes**                                   | Gaussian processによるgradient matchingは、(dx/dt) 推定の統計的基準として有用 | 式構造の生成や層解析は扱わない                    |
| **LASF / A Layer-wise Analysis of Supervised Fine-Tuning** | 2026年のACL論文で、情報理論的・幾何学的・最適化的な指標を用いてfine-tuningによる変化を層ごとに分析している。中間層と最終層で異なる感度を示し、選択的な層更新も提案。重み変化・表現変化・忘却・層選択FT・LoRAとの比較を**一つの実験系で扱う**点が参考になる | LLMのSFT研究であり、NeSymReSやencoder–decoder SRへ直接は対応しない |
| **D-CODE / D-CODE: Discovering Closed-form ODEs from Observed Trajectories**                                 | 観測軌道から閉形式ODEを発見する研究。単純な教師ありSRとしてではなく、ODE制約と観測軌道を利用して式を探索する。ODEFormerやSINDyとともに、GRN軌道から方程式を発見する比較手法として利用できる | 比較手法であり、Transformer内部の層解析は扱わない       |
| **DGSR / Deep Generative Symbolic Regression with Monte-Carlo-Tree-Search** | 事前学習したニューラルモデルとMCTSを組み合わせ、OODデータ上で探索能力を補う研究。「TPSR固有の効果」と「ニューラル事前分布＋MCTS一般の効果」を区別するための関連研究として有用。ND2もNeSymReS・同論文・TPSRを並べて引用している | TPSRと目的が近く、層解析の直接的対象ではない            |
| **UFDSR / A Unified Framework for Deep Symbolic Regression** | RNN・強化学習型SRを統一的に扱う研究。ScaleSRの関連研究でも主要なニューラルSRとして引用されており、NeSymReS以外のニューラル式生成と比較するときに有用 | 層解析では優先度が下がる                       |
| **DSR / Deep Symbolic Regression**               | risk-seeking policy gradientで式を生成する代表的ニューラルSR。「事前学習型／強化学習型／進化計算型」というNSRの分類を説明するために必要 | Transformerではないため層解析の直接的対象にはならない    |
